# 5. Hacer inventario (Conteos físicos) 🧮

**¿Para qué?** Contar lo que hay físicamente y dejar que el sistema **ajuste solo** las diferencias.
**¿Quién?** Cuenta: bodega. Aprueba: jefe de bodega.
**Dónde:** Inventario → **Conteos físicos**.

## El flujo
**BORRADOR** (cuentas y guardas) → (aprobar) → **APROBADO** (el stock se reconcilia solo)

## Paso a paso
1. Clic en **Nuevo conteo**.
2. **Bodega** que vas a contar.
3. **Tipo de conteo**:
   - **General** (toda la bodega), **Parcial** (algunos productos), **Cíclico** (rutina periódica).
4. Por cada producto, agrega una línea con la **Cantidad contada** (lo que contaste físicamente).
5. (Opcional) **Notas** → guardar. Queda en **BORRADOR**.

## Revisar y aprobar
1. Abre el conteo con **Ver**: el sistema muestra **Sistema vs Contado vs Diferencia**.
   - 🔴 Diferencia negativa = **faltante**. 🟢 Positiva = **sobrante**.
2. Si las diferencias son correctas, el jefe da **Aprobar conteo**.
3. Al aprobar, el sistema **ajusta el stock** automáticamente para que cuadre con lo contado.

## Importante
- Mientras esté en **borrador** no cambia nada; el ajuste ocurre **solo al aprobar**.
- Cuenta con calma: lo que apruebes pasa a ser la verdad del sistema.
- Sirve para arrancar: para cargar el **stock inicial** de una bodega, haz un conteo y apruébalo.
