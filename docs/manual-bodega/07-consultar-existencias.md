# 7. Consultar existencias e historial 🔎

**¿Para qué?** Saber cuánto hay, dónde, y revisar el historial de cada producto.
**¿Quién?** Todos (incluido el rol de solo consulta).
**Dónde:** Inventario → **Existencias**.

## Ver cuánto hay
- **Existencias** muestra cada producto por bodega con:
  - **Disponible** (lo que puedes usar), **Reservado** (comprometido), **Valor**.
- Usa el **buscador** para encontrar un producto por nombre o código.

## Ver movimientos (entradas y salidas)
- Existencias → **Movimientos**: lista todo lo que entró y salió, con fecha, tipo y referencia.

## Ver el Kardex (historial valorizado de un producto)
- Existencias → **Kardex**: elige un producto y verás, en orden, cada entrada/salida con el **saldo** y el **costo promedio** después de cada movimiento.
- Es la "hoja de vida" del producto: sirve para auditar y entender por qué el stock o el costo está como está.

## Consejos
- ¿El número no cuadra con lo físico? Revisa primero el **Kardex** para ver qué pasó; luego corrige con **Ajuste** o **Conteo**.
- **Disponible = En mano − Reservado.** Si "Disponible" es bajo pero físicamente hay, puede haber stock reservado por una solicitud.
