# 4. Corregir existencias (Ajustes) 🎚️

**¿Para qué?** Corregir el stock cuando la realidad no coincide con el sistema: daño, robo, pérdida o error. **Todo queda trazado.**
**¿Quién?** Jefe de bodega (o quien tenga el permiso).
**Dónde:** Inventario → **Ajustes**.

## Paso a paso
1. Clic en **Nuevo ajuste**.
2. **Bodega** donde está la diferencia.
3. **Motivo** (elige el correcto):
   - **Daño**, **Robo**, **Pérdida** → mercancía que ya no está.
   - **Error operativo** / **Corrección administrativa** → arreglar un registro mal hecho.
   - **Diferencia de conteo** → ajuste tras un inventario.
4. **Fecha** (normalmente hoy).
5. Agrega líneas con el producto y la **Δ Cantidad** (la diferencia, **con signo**):
   - Escribe **negativo** para **sacar** (ej. `-3` por una caneca derramada).
   - Escribe **positivo** para **entrar** (ej. `+5` si apareció mercancía).
6. (Opcional) **Notas**, **URL de evidencia** (foto) → **Registrar ajuste**.

## Importante ⚠️
- El ajuste **NO se puede deshacer**: queda en el kardex para siempre. Verifica antes de guardar.
- Siempre pon el **motivo real** y, si puedes, una **nota/foto**. Es lo que te respalda en una auditoría.
- ¿Diferencias de un inventario completo? Mejor usa **Conteos físicos** (página 5), que ajusta solo.

## Regla
**Daño/Robo/Pérdida = número negativo.** Si dudas del signo, pregunta antes de guardar.
