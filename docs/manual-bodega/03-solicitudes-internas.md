# 3. Pedir material (Solicitudes internas) ✅

**¿Para qué?** Que un área pida material a bodega, se apruebe y se entregue. El despacho **descuenta stock**.
**¿Quién?** Crea: cualquiera de bodega. Aprueba: jefe. Despacha: bodega.
**Dónde:** Inventario → **Solicitudes internas**.

## El flujo (3 estados)
**PENDIENTE** → (aprobar) → **APROBADA** → (despachar) → **DESPACHADA**

## Crear una solicitud
1. Clic en **Nueva solicitud**.
2. **Área** que pide (ej. Producción, Mantenimiento).
3. **Bodega** de donde saldrá el material.
4. Agrega líneas: **Producto** + **Cant.**
5. (Opcional) **Notas** → guardar. Queda en **PENDIENTE**.

## Aprobar (jefe de bodega)
- Revisa la solicitud → botón **Aprobar**. Pasa a **APROBADA**.

## Despachar (entregar)
- En una solicitud aprobada → botón **Despachar**.
- Esto **descuenta el stock** y la deja en **DESPACHADA**. Entrega el material físico.

## Cancelar
- Botón **Cancelar** (mientras esté pendiente o aprobada). Una despachada **no** se cancela.

## Importante
- No se puede despachar más de lo que hay: si no hay stock, el sistema lo impide.
- Usa **Ver** para revisar qué se pidió y cuánto se despachó.
